# 电商订单数据分析（pandas + pyecharts）

基于和鲸社区 3 份互不相关的电商数据集，用 pandas 完成清洗与分析、pyecharts 出图的练习项目。三个数据集各自独立成篇。

## 数据集

均来自和鲸社区公开数据集，已随仓库上传（共约 7MB）：

- `tmall_order_report.csv`：天猫订单报表，28010 条订单记录
- `双十一淘宝美妆数据.csv`：美妆店铺双十一销售数据
- `日化.xlsx`：美妆批发订单数据，含订单表与商品表两个 sheet

## 技术栈

Python / pandas / pyecharts / Jupyter Notebook

## 项目结构

- `电商订单分析.ipynb`：完整分析过程（含清洗、统计、可视化代码与输出），分三部分：
  - Part 1 天猫订单：整体情况、地区分布、下单时间规律
  - Part 2 双十一美妆：每日销量走势、店铺销量/均价排名
  - Part 3 日化订单：月度趋势、地区与品类需求、RFM 客户价值分层

## 复现

1. 装好依赖：`pip install pandas pyecharts jupyter`
2. 在仓库目录下启动 notebook：`jupyter notebook 电商订单分析.ipynb`
3. 自上而下运行即可（数据文件就在同目录）

## 核心结论

- 天猫订单：2 月上半月受疫情影响订单低迷，复工后明显回升；下单高峰为 10 点、15 点、21 点
- 双十一美妆：头部店铺销量集中，可对比店铺均价区分走量款与高端款
- 日化订单：用 RFM 模型给客户打分分层，80 分以上标记为优质客户优先服务
